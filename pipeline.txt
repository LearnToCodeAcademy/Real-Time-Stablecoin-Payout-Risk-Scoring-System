MULTI-TOKEN PIPELINE (USDT, USDC, BUSD, DAI, USDP, TUSD)
=========================================================

🔥 STEP 1: RUN MAIN.PY (ONE TIME)
main.py → Generates all token CSVs:
  - v0_usdt.csv, v0_usdc.csv, v0_busd.csv, etc.
  - v1_usdt.csv, v1_usdc.csv, v1_busd.csv, etc.
  - v2_usdt.csv, v2_usdc.csv, v2_busd.csv, etc.
  - v3_raw_usdt.csv, v3_raw_usdc.csv, v3_raw_busd.csv, etc.

=========================================================
🔥 STEP 2: RUN PER-TOKEN SCRIPTS (LOOP THROUGH EACH TOKEN)
=========================================================

For each TOKEN in [usdt, usdc, busd, dai, usdp, tusd]:

V0 (BASELINE):
  1. cleaner.py (set TOKEN = "usdt" at top)
     v0_usdt.csv → usdt_training_ready.csv
  
V1 (HIGH-TRUST MALICIOUS):
  2. auto_assign_V1_V2.py (set TOKEN = "usdt", VERSION = "v1")
     v1_usdt.csv → usdt_labeled_auto.csv
  
V2 (SCALED MALICIOUS):
  3. auto_assign_V1_V2.py (set TOKEN = "usdt", VERSION = "v2")
     v2_usdt.csv → usdt_labeled_v2.csv
  
V3 (POISONING BEHAVIOR):
  4. v3_processor.py (set TOKEN = "usdt")
     v3_raw_usdt.csv → usdt_labeled_v3.csv
  
V4 (HIGH-CONFIDENCE SAFE):
  5. v4_script.py (set TOKEN = "usdt")
     usdt_training_ready.csv → usdt_labeled_v4.csv

=========================================================
🔥 STEP 3: TRAIN MODEL (PER TOKEN)
=========================================================

train_ml.py (set TOKEN = "usdt" at top)
  Combines: usdt_training_ready.csv + usdt_labeled_auto.csv + 
            usdt_labeled_v2.csv + usdt_labeled_v3.csv + usdt_labeled_v4.csv
  Outputs: usdt_model.pkl, usdt_scaler.pkl, usdt_features.pkl

=========================================================
🔥 INFERENCE
=========================================================

wallet_check.py
  - Auto-detects token from wallet transactions
  - Loads appropriate model (usdt_model, usdc_model, etc.)
  - Scores wallet in real-time
